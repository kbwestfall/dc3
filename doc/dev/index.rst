===========
Development
===========

Documentation for ``dc3`` developers: the reasoning behind design decisions,
and characterizations of the code's numerical behaviour that the decisions
rest on.  These pages are not needed to *use* ``dc3``.

Figures on these pages are produced by the scripts in ``doc/scripts/`` and
committed to the repository; the documentation build does not run them.
Regenerate them from ``doc/`` with ``make figures``.
